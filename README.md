# Помощник торгового — презентация

Обзор возможностей приложения для торгового представителя: зарплата и выполнение плана,
долги точек, записи на оплату, советы по ассортименту, разбор точки для разговора с магазином.

**Открыть:** https://dairsadru.github.io/pomoshnik-torgovogo/

Страница читается с телефона: скриншоты листаются пальцем, любой открывается на весь экран.

Все названия, имена и суммы на скриншотах вымышленные — интерфейс и функции настоящие.
Страница закрыта от поисковиков (`noindex` + `robots.txt`): открывается только по прямой ссылке.

Содержимое собирается скриптом `build_presentation.py` из соседней рабочей папки:
текст и список экранов лежат в нём, `site/` целиком генерируется.
